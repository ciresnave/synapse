# Archived reports

Point-in-time completion, fix and audit write-ups from before the 6.0.0 release-candidate series, moved here from the
repository root in rc.57. They are history, not current documentation: their claims were true (or were marked as corrected)
at the date in each file, and some are checked by tests so that a corrected claim cannot silently go stale
(`tests/empty_test_files_are_named.rs`, `tests/integration_summary_matches_manifest.rs`,
`tests/security_claims_match_the_tree.rs`). Their full history is in git.

| `COMPILATION_FIXES_COMPLETE.md` | compilation-fixes report, with a correction on `enhanced-auth` |
| `CRITICAL_SECURITY_FIXES.md` | security-fixes report |
| `ENTERPRISE_IMPLEMENTATION_COMPLETE.md` | feature-completion report (2026-06-12) |

| `IMPLEMENTATION_COMPLETION_REPORT.md` | completion report (2026-06-12) |
| `SECURITY_AUDIT_COMPLETION_REPORT.md` | security audit report, with a correction |
